# The Memory Detective - Game Design Document

**Date**: 2025.11.06
**Version**: 1.0
**Language**: Rust

## Executive Summary

A text-based murder mystery where the player, a psychometric detective, solves a 1920s mansion murder by experiencing fragmented, emotionally-colored memories of witnesses and objects. The game combines classic adventure puzzles with psychological thriller elements and an unreliable narrator system.

## Core Gameplay Loop

```
Explore Mansion → Touch Objects → Experience Memory Fragment →
Gather Evidence → Find Contradictions → Reconstruct Timeline →
Accuse Suspect → Win/Lose Based on Accuracy
```

struct Evidence {

## Game Content Design

### Setting: Ashford Manor, October 31, 1925

**The Victim**: Lord Edmund Ashford, 58, wealthy industrialist
**Time of Death**: Between 9:00 PM and 10:00 PM
**Location**: Study
**Cause**: Blunt force trauma (candlestick)

### Suspects (6 Total)

1. **Lady Margaret Ashford** (Wife, 45)
   - Motive: Inheritance, loveless marriage
   - Alibi: In conservatory with witnesses
   - Secret: Having affair with the butler
   - Memory emotion: Guilty fear

2. **Dr. Thomas Blackwood** (Business Partner, 52)
   - Motive: Edmund discovered embezzlement
   - Alibi: In library reading
   - Secret: Forged business documents
   - Memory emotion: Desperate anxiety

3. **Charlotte Ashford** (Daughter, 23)
   - Motive: Father forbidding her marriage
   - Alibi: In her room writing letters
   - Secret: Pregnant, desperate
   - Memory emotion: Angry resentment

4. **James Hartley** (Butler, 38)
   - Motive: Affair with Lady Margaret, protecting her
   - Alibi: Serving drinks in drawing room
   - Secret: Was near study at time of murder
   - Memory emotion: Protective loyalty

5. **Victor Crane** (Rival Industrialist, 60)
   - Motive: Business competition, grudge
   - Alibi: Smoking in garden
   - Secret: Threatened Edmund earlier
   - Memory emotion: Barely contained rage

6. **Miss Evelyn Price** (Secretary, 28)
   - Motive: Edmund rejected her advances, humiliated her
   - Alibi: In kitchen helping with dinner
   - Secret: Witnessed something she won't reveal
   - Memory emotion: Humiliated anger

### The Truth (Example Solution)

**Actual Killer**: Charlotte Ashford
**Method**: Confronted father about marriage, argument escalated, struck him in rage
**Cover-up**: James Hartley witnessed it, helped stage scene to protect Charlotte (whom he sees as daughter)
**Red Herrings**: Victor's threats, Thomas's embezzlement, Margaret's affair all look suspicious

### Key Locations (12 Total)

1. **Grand Foyer** - Entry point, stairs to upper floor
2. **Drawing Room** - Where guests gathered
3. **Study** - Crime scene (locked until discovered)
4. **Library** - Book-lined, secret passage
5. **Dining Room** - Dinner was served here
6. **Kitchen** - Staff area
7. **Conservatory** - Glass room with plants
8. **Garden** - Outside, fountain, paths
9. **Master Bedroom** - Edmund and Margaret's room
10. **Charlotte's Room** - Daughter's bedroom
11. **Guest Rooms** - Where others stayed
12. **Servants' Quarters** - Butler's room, evidence

### Key Objects & Their Memories

1. **Candlestick** (Murder weapon)
   - Touch: Blurred memory of impact, Charlotte's scream (unreliable, emotional)
   - Focus: See her hand gripping it, ring visible

2. **Letter in Charlotte's Room**
   - Touch: Memory of writing it, desperation
   - Focus: Addressed to forbidden lover

3. **Wine Glass in Drawing Room**
   - Touch: Memory of Victor's toast, veiled threat
   - Focus: Edmund's nervous reaction

4. **Business Ledger in Study**
   - Touch: Thomas's memory of falsifying entries
   - Focus: Dates show pattern of embezzlement

5. **Broken Watch** (Found in study)
   - Touch: Struggle, stops at 9:47 PM
   - Focus: Edmund's hand, defensive wounds

6. **Garden Fountain**
   - Touch: Memory of James and Margaret's secret meeting
   - Focus: Their whispered conversation about "protecting Charlotte"

7. **Photograph** (Family portrait)
   - Touch: Memory of happier times, Edmund's pride in Charlotte
   - Focus: Charlotte's current resentment contrasts

## Progressive Revelation System

### Phase 1: Surface Memories (Easy to Access)
- Alibis as characters remember them
- Public actions and statements
- Obvious evidence

### Phase 2: Deeper Memories (Require FOCUS)
- Details that reveal inconsistencies
- Emotional undertones
- Hidden observations

### Phase 3: Repressed Memories (Require Specific Triggers)
- Trauma-blocked memories
- Witness to murder (Evelyn)
- Actual killing (Charlotte)
- Cover-up actions (James)

**Trigger Examples:**
- Show evidence to person to unlock their deeper memory
- Experience other memories that "resonate"
- Build trust through conversation
- Reach certain game phase

## Command Reference

### Core Commands
- **LOOK** / **L** - Describe current location
- **GO [direction]** / **N/S/E/W** - Move
- **EXAMINE [object]** / **X [object]** - Detailed look
- **INVENTORY** / **I** - Show carried items
- **HELP** - Command list

### Investigation Commands
- **TOUCH [object/person]** - Experience associated memory
- **FOCUS ON [detail]** - Examine memory fragment deeper
- **REMEMBER [topic]** - Recall gathered information
- **COMPARE [memory] WITH [memory]** - Find contradictions
- **TIMELINE** - View reconstructed timeline of events
- **NOTES** - View evidence and contradictions

### Interaction Commands
- **TALK TO [person]** - General conversation
- **ASK [person] ABOUT [topic]** - Specific questioning
- **SHOW [item] TO [person]** - Present evidence
- **CONFRONT [person] ABOUT [topic]** - Challenge inconsistency
- **ACCUSE [person]** - Make final accusation (locks choice)

## Win Conditions & Endings

### Perfect Solution
- Accuse correct killer (Charlotte)
- Identify accomplice (James)
- Understand motive
- Reconstruct accurate timeline
- Find all key evidence

**Ending**: Full confession, justice served, you're hailed as brilliant detective

### Good Solution
- Accuse correct killer
- Miss some details about accomplice

**Ending**: Killer convicted, but you feel something's incomplete

### Partial Solution
- Accuse wrong person but with plausible evidence
- (e.g., James who helped cover up)

**Ending**: Wrong person convicted, real killer goes free, you doubt yourself

### Failure
- Accuse obviously wrong person
- Insufficient evidence

**Ending**: Dismissed from case, murder goes unsolved

### Hidden Ending: Mercy
- Discover the truth but choose not to accuse
- Understand the tragedy of the situation

**Ending**: You falsify your report, letting Charlotte go free. Live with the choice.
