# Ranked Command Line Games - Top 100

## Ranking Criteria
Games are scored on a 100-point scale based on:
- **Fun Factor** (25 points): How entertaining and engaging
- **Implementation Ease** (20 points): Simpler to code scores higher
- **Replayability** (20 points): Long-term play value
- **Educational Value** (15 points): Learning potential
- **Uniqueness** (10 points): Originality in CLI context
- **Broad Appeal** (10 points): Universal enjoyment potential
