================================================================================
KNOWN LIMITATIONS
================================================================================

1. TERMINAL SIZE
   - Minimum required: 80x24
   - Large mazes (>100x100) may not fit
   - Mitigation: Viewport rendering implemented

2. ALDOUS-BRODER PERFORMANCE
   - Slow for mazes > 50x50
   - O(n²m²) worst-case complexity
   - Mitigation: Binary Tree recommended for speed

3. SINGLE-THREADED GENERATION
   - Generation not parallelized
   - Not needed: Sequential generation fast enough
   - Future: Can be optimized if needed

4. RENDERING RESOLUTION
   - ASCII-only, no graphics
   - Terminal character-based display
   - Feature: Can be extended to GUI in future
