# Color Chain Reaction Game Design

## System Architecture

### Core Components

#### 1. Game State
```typescript
interface GameState {
  board: Orb[][];
  score: number;
  movesRemaining: number;
  levelId: number;
  gameStatus: 'playing' | 'won' | 'lost' | 'paused';
  selectedOrbs: Set<Orb>;
}
```

#### 2. Orb Class
```typescript
enum OrbType {
  Normal = 'normal',
  Rainbow = 'rainbow',     // Matches any color
  Black = 'black',         // Blocks chains
  Mirror = 'mirror'        // Duplicates on match
}

enum OrbColor {
  Red = 'red',
  Blue = 'blue',
  Green = 'green',
  Yellow = 'yellow',
  Purple = 'purple'
}

interface Orb {
  id: string;
  type: OrbType;
  color: OrbColor | null;  // null for black orbs
  x: number;
  y: number;
  vx: number;              // velocity x
  vy: number;              // velocity y
  radius: number;
  isExploded: boolean;
}
```

#### 3. Physics Engine
- **Velocity-based movement**: Each orb has vx, vy
- **Collision detection**: Circle-circle collision at distance threshold
- **Gravity**: Orbs fall when unsupported (optional for harder difficulty)
- **Damping**: Velocity reduces over time

#### 4. Chain Reaction System
```typescript
interface ChainReaction {
  triggerOrbId: string;
  matchedOrbs: Set<string>;
  affectedByMirror: Set<string>;
  explosionEnergy: number;
}
```

**Algorithm**:
1. User clicks orb -> trigger explosion
2. Find all adjacent orbs of matching color (BFS/DFS)
3. Mark matched orbs for removal
4. Apply physics force to nearby orbs
5. If mirror orbs affected, duplicate explosion in opposite direction
6. Remove exploded orbs from board
7. Apply gravity/slide physics for falling orbs
8. Repeat for any new matches (cascading)
9. Count matches, update score

#### 5. Level System
```typescript
interface Level {
  id: number;
  name: string;
  boardLayout: OrbData[][];  // Initial orb configuration
  targetScore: number;
  movesLimit: number;
  difficulty: 'easy' | 'medium' | 'hard';
  specialOrbsRequired: boolean;
}
```

### Board Layout

**Standard Grid**: 8x8 or 6x8 orbs
- Each cell contains either an orb or empty space
- Orbs can move via physics

### Scoring System
- Basic match: 10 points per orb
- Cascade bonus: +5 points per additional match in reaction
- Perfect clear: +100 bonus points
- Remaining moves bonus: movesLeft * 2 points

### Game Flow
1. Display level objective
2. Render initial board
3. Wait for player click
4. Process click:
   - Detect which orb was clicked
   - Trigger chain reaction
   - Deduct move count
   - Check win/lose conditions
5. Update board state
6. Repeat until board cleared or moves exhausted

### Special Orb Behaviors

**Rainbow Orb**:
- Matches any color when triggered
- Creates explosion of all adjacent colors

**Black Orb**:
- Cannot be clicked
- Stops chain reaction propagation
- Blocks movement paths

**Mirror Orb**:
- When matched, creates duplicate explosion
- Duplicates in opposite direction from original
- Can create self-sustaining reactions if configured carefully

## Physics Simulation

### Force Application
```
When orb explodes:
- Nearby orbs gain velocity vector away from explosion center
- Force magnitude = baseForce / distance
- Cap maximum velocity at 10 units/frame
```

### Movement
```
Each frame:
- position += velocity
- velocity *= damping (0.95)
- Apply collision response
- Check board boundaries
```

### Collision Handling
```
If orb-orb distance < radius1 + radius2:
- Push orbs apart
- Exchange some velocity
- Optional: elastic/inelastic collision
```

## Known Constraints & Simplifications

1. **No persistent gravity**: Orbs don't continuously fall; they only adjust positions after explosions
2. **Discrete grid positions**: Orbs snap to grid after physics resolution
3. **Instant matching detection**: No animation delay for finding matches
4. **Linear difficulty**: Levels increase steadily; no randomization
5. **Max 25 levels**: Manageable scope for development
