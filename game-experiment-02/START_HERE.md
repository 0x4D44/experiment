# ASTEROID DEFENDER - START HERE

Welcome to Asteroid Defender! This is your complete game submission.

## QUICK START - Play the Game NOW

### Easiest Way to Play
1. **Open this file in your browser**: `game.html`
2. **Press R** to start the game
3. **Use arrow keys or WASD** to move your spaceship
4. **Move your mouse** to aim
5. **Click** to shoot asteroids
6. **Survive 5 waves** to win!

That's it! No installation, no build process, just open and play.

## How to Win

Destroy all asteroids in all 5 waves:
1. Wave 1: 3 asteroids (easy)
2. Wave 2: 4 asteroids (easy-medium)
3. Wave 3: 5 asteroids (medium)
4. Wave 4: 6 asteroids (medium-hard)
5. Wave 5: 7+ asteroids (hard boss fight)

Each wave gets faster - stay focused!
