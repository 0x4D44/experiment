# Beat Maker Quest - Development Journal

## Project Overview
Building a music/rhythm creation game for game development competition Round 3.

### Requirements
- Grid-based sequencer (8x8 or 16x16)
- Multiple instrument tracks (drums, bass, melody)
- Puzzle mode: recreate target melodies
- Sandbox mode: free creation
- BPM control and play/pause
- Save/load patterns
- Visual feedback (lights, colors) synced to beats
- At least 8 different instrument sounds
- Score based on accuracy in puzzle mode

### Technology Stack
- **Language**: TypeScript (for web delivery, familiar with codebase patterns)
- **Runtime**: Browser (HTML5 Canvas + Web Audio API)
- **Testing**: Jest
- **Build**: TypeScript compilation

---

## Design Decisions

### Architecture
1. **Web-based**: HTML5 Canvas for visualization, Web Audio API for sound generation
2. **Grid System**: 16x16 grid supporting 8 instrument tracks × 16 time steps
3. **Instrument Model**: Each track has notes that can be placed on grid cells
4. **Playback Engine**: Uses AudioContext to schedule notes with precise timing

### Data Model
- Sequencer State: grid[track][step] = note
- Patterns: Saveable/loadable sequences with metadata
- Instruments: Synthesized sounds with different waveforms and ADSR envelopes
