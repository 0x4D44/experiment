## Architecture

### Core Classes
1. **GameBoard** - 20x20 grid, bounds checking, utilities
2. **Snake** - Segments, direction, movement, growth
3. **FoodManager** - Food spawning, power-up management
4. **PowerUpSystem** - Active power-up tracking, duration
5. **SnakePlusGame** - Main engine, game state, updates

### Game Design
- Grid-based movement (20x20 cells)
- Frame-based updates (configurable speed)
- Three power-up types with different effects
- Progressive difficulty (speed increases every 5 food)
- Score system with multipliers

## Challenges & Solutions

### Challenge 1: Workspace Auto-Generation
**Issue**: Files were being auto-deleted/overwritten by workspace auto-generation
**Solution**: Created game code as single comprehensive file in src/snakeplusgame.ts
**Outcome**: Clean separation of game logic from other projects

### Challenge 2: TypeScript Module Resolution
**Issue**: Import paths changing due to file reorganization
**Solution**: Used consistent path structure with proper tsconfig.json
**Outcome**: All tests can import game classes correctly

## Power-Up System Details

1. **Speed Boost** (Green)
   - Duration: 300 frames (~5 seconds at 60 FPS)
   - Effect: Doubles snake speed
   - Bonus: +50 points

2. **Invincibility** (Gold)
   - Duration: 240 frames (~4 seconds at 60 FPS)
   - Effect: Immunity to collisions
   - Bonus: +50 points

3. **Score Multiplier** (Red)
   - Duration: 180 frames (~3 seconds at 60 FPS)
   - Effect: Double food points (10 -> 20 per food)
   - Bonus: +50 points
