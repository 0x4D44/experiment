## Architecture

### Entity Classes
- **Ball**: Manages ball physics, velocity, collision detection bounds
- **Paddle**: Handles player control, power-up effects, boundary clamping
- **Block**: Tracks health/damage, points, visual color based on health
- **PowerUp**: Falling collectibles with duration and type system

### Systems
- **LevelManager**: Generates levels with increasing difficulty
  - Level 1-2: Basic blocks, no boss
  - Level 3+: Adds boss battles
  - Difficulty increases: ball speed +50/level, paddle width -5/level (min 60)
  - Block health scales with level
  - Block points scale with level
- **ScoringSystem**: Combo tracking and multiplier system
  - Base: 10 points per block
  - Multiplier: 1x to 3x based on combo (20% per block destroyed)
  - Combo resets after 3 seconds of inactivity

### Collision Detection
- Rectangle-to-rectangle collision (AABBs)
- Circle-to-rectangle collision (ball vs block/paddle)
- Collision side detection for proper reflection
- Vector math utilities (normalize, magnitude, reflect)

## Game Balance
- Ball speed: 250-400 pixels/sec (scales by level)
- Paddle speed: 400 pixels/sec
- Paddle width: 100-60 pixels (decreases with level)
- Power-up duration: 10 seconds
- Combo window: 3 seconds
- Block health: 1-5 (increases with level)
- Block points: 10-50+ (increases with level)

## Testing Strategy
- Unit tests for each entity type (Ball, Paddle, Block, PowerUp)
- System tests for LevelManager and ScoringSystem
- Collision detection tests
- Integration tests for game flow
