# Hex Commander Development Journal

**Project**: Hex Commander - Turn-Based Strategy Game
**Start Date**: 2025-11-07
**Framework**: TypeScript + HTML5 Canvas

## Vision
Build a fully functional hexagonal grid strategy game with multiple unit types, terrain effects, fog of war, and AI opponent for the Round 2 competition.

## Game Requirements
- Hexagonal tile-based map (at least 10x10)
- Unit types: Infantry, Cavalry, Archers
- Terrain affects movement and combat
- Resource nodes to capture and hold
- Simple AI opponent
- Fog of war based on unit vision
- Victory through elimination or point control

## Technical Stack Decision
- **Language**: TypeScript (aligns with existing project setup, good for browser games)
- **Rendering**: HTML5 Canvas (lightweight, no external dependencies needed)
- **Testing**: Jest (already configured in project)

## Design Decisions Log

### Session 1: Initial Planning (2025-11-07)
- Chose TypeScript + Canvas for rapid development and testability
- Will use axial coordinate system for hexagons (industry standard)
- Starting with modular architecture: Game, Map, Unit, AI systems
- Test-driven development approach for critical systems

## Testing Strategy
- Unit tests for: hex coordinates, movement validation, combat calculations
- Integration tests for: game state transitions, AI decision making
- Manual testing: gameplay flow, victory conditions

## Performance Considerations
- Hex grid will use axial coordinates for O(1) lookups
- Fog of war cached per turn
- AI uses simple heuristics, not pathfinding initially
