## Project Overview
Creating a particle physics sandbox puzzle game with:
- Particle simulation with mass, charge, velocity properties
- Attractors and repulsors for particle manipulation
- Goal-based puzzle mode with 15+ levels
- Sandbox mode for experimentation
- Visual trail rendering

- Environmental effects (gravity fields, barriers, portals)

## Architecture Decisions

### Technology Stack
- **Language:** TypeScript (compiled to JavaScript for web)
- **Rendering:** HTML5 Canvas 2D
- **Physics Engine:** Custom lightweight particle system
- **Testing:** Jest (unit and integration tests)
- **Deployment:** Single HTML file with embedded JS

### Design Patterns
1. **Particle System**: Class-based architecture
   - Particle class: stores position, velocity, mass, charge, type
   - ParticleManager: handles simulation and updates
   - Renderer: Canvas-based visualization

2. **Physics Simulation**:
   - Coulomb force (charge interactions)
   - Gravity simulation
   - Collision detection and response
   - Force accumulation and integration

3. **Puzzle System**:
   - Level definition with goals and attractor placement
   - Goal region detection
   - Win/loss conditions

4. **UI System**:
   - Canvas for rendering
   - HTML controls for mode selection
   - Mode toggle (Puzzle vs Sandbox)

## Technical Challenges & Solutions

### Challenge 1: Accurate Physics Integration
- Need stable numerical integration without particles flying off
- **Solution:** Use velocity Verlet integration or semi-implicit Euler
- Test with known scenarios (orbit, stable states)

### Challenge 2: Collision Performance
- With many particles, O(n²) collision detection can be slow
- **Solution:** Start with quadtree spatial partitioning if needed
- May use simple distance check first, optimize later if needed

### Challenge 3: Visual Trail Performance
- Drawing all particle trails every frame is expensive
- **Solution:** Use off-screen canvas for trails, fade over time
- Limit trail length to recent N positions

### Challenge 4: Interesting Level Design
- Need puzzles that are challenging but solvable
- **Solution:** Start with simpler mechanical levels
- Use combination of attractors, repulsors, and barriers

## Implementation Notes

### Particle Types
- **Neutral (gray):** Only affected by gravity and collision
- **Positive (red):** Repelled by positive, attracted to negative
- **Negative (blue):** Attracted to positive, repelled by negative

### Force Calculations
- Coulomb Force: F = k * q1 * q2 / r²
- Gravity: F = G * m1 * m2 / r²
- Distance threshold to prevent infinite forces

### Simulation Loop
1. Apply forces to all particles
2. Update velocities based on forces
3. Update positions based on velocities
4. Check collisions
5. Check goal conditions
6. Render
