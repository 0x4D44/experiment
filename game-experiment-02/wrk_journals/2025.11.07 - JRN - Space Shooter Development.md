## Architecture Decisions
- Using simplified entity-component pattern (not full ECS)
- Base `Entity` class for physics
- Specialized entity types: `Player`, `Asteroid`, `Enemy`, `Projectile`
- Separate manager systems: `EntityManager`, `CollisionManager`, `WaveManager`
- Canvas-based 2D rendering
