# 2025.11.07 - Word Warrior Development Journal

## Project Overview
Creating a typing game with combat elements for the game development competition Round 2.

### Game Concept
- **Core Mechanic**: Type words to cast spells and attack enemies
- **Difficulty Scaling**: Longer/harder words deal more damage
- **Combo System**: Reward typing speed and accuracy
- **Word Categories**: Fire words, Ice words, Earth words, Lightning words
- **Boss Battles**: Special typing challenges with boss enemies
- **Character Progression**: Abilities unlocked through typing achievements
- **Dictionary**: 500+ words with difficulty ratings (1-5 stars)

### Technical Stack
- **Language**: TypeScript (web-based)
- **Framework**: Vanilla HTML5/Canvas with TypeScript
- **Testing**: Jest for unit tests
- **Build**: npm with TypeScript compiler
