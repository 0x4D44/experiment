## Design Decisions

### Technology Stack
- **Language:** Rust (pure, no external UI framework)
- **Game Type:** Minimalist tower defense
- **Display:** ASCII-art console UI with real-time rendering
- **Testing:** Comprehensive unit tests (15+ test cases)

### Game Architecture
- **Game Engine:** Turn-based with discrete time steps
- **State Management:** Owned Game struct with Vec-based collections
- **Tower System:** Three distinct tower types with unique mechanics
- **Enemy System:** Positional-based with health, speed, and status effects
- **Wave System:** Progressive scaling with level-based parameters

### Core Game Systems

1. **Wave System:**
   - Level 1: 3 waves
   - Level 5: 8 waves
   - Enemies spawn at 1 per turn during active wave

2. **Tower System:**
   - Gun: Fast, moderate damage, range 2
   - Slow: Status effect (reduce movement), range 3
   - Bomb: Area effect, range 2
   - Upgrade system with scaling costs

3. **Resource System:**
   - Starting gold: 200-400 depending on level
   - Enemy rewards: 10-50 gold depending on level
   - Tower costs: 80-120 gold
   - Upgrade costs: 50*level gold

4. **Difficulty Progression:**
   - 5 levels with increasing enemy health
   - Faster enemy movement at higher levels
   - Reduced starting health at higher difficulties

## Challenges & Solutions

### Challenge 1: Rust Borrow Checker
**Problem:** Mutably borrowing towers while immutably calling find_target
**Solution:** Deferred tower actions - collect all actions first, apply them after

### Challenge 2: Environment Interference
**Problem:** Unknown process (IDE watcher/formatter) deleting Rust source files and replacing them with TypeScript template files
**Symptoms:**
- src/game.rs, src/main.rs, src/ui.rs files deleted after write
- Cargo.toml overwritten with different project name (dungeon_delver)
- Happens immediately after file creation
- Affects both tools/write operations and bash file creation

**Impact:** Severely hampered development workflow, required multiple restarts
**Investigation:**
- Checked .git/hooks: Only samples, no active hooks
- Checked parent directory: Git folder at /experiment level
- File permissions: Standard read-write
- Process: Appears to be automatic, not user-triggered

**Workaround:** Documented in final solution - use /tmp for development, copy/document in cwd

## Key Implementation Details

### Tower Combat Logic
```
1. Collect tower targets (avoid borrow conflicts)
2. Apply actions based on tower type:
   - Gun: Single target damage
   - Slow: Apply slow effect to single target
   - Bomb: Area damage around target position
3. Reset tower cooldowns
```

### Enemy Movement
```
1. Each tick, increment speed_counter
2. When counter >= effective_speed:
   - Move to next position
   - Reset counter
3. Slowed enemies have 2x movement cost
```

### Game State Flow
```
Spawn -> Move -> Tower Attack -> Damage Resolution -> Cleanup -> Check Win/Lose
```
